acceptance.json保存114项Node检查、Web Mobile构建成功（退出36）、393×852 DPR2的三次自然球阵DOM触摸开球（24项）、320×568 DPR1与430×932 DPR3各一次（8项）。没有注入目标球速度或重排球阵；通过摆球、瞄准、力度条和出杆按钮完成。220ms触球帧采样速度约7.9925 m/s，是8 m/s提交后经过首个物理子步的采样值。

浏览器额外回归：对局35、打点28、六袋28（包含8 m/s）、完整受控球局14、异常输入17、触球时序9均通过。类型检查与114项Node测试包括加强力度曲线、220ms唯一提交、两个8 m/s球对冲、满力碰库、极端打点能量与三种开球位置的量化门槛。未新增手机或微信验证。
