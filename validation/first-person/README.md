2026-10-26，基线 `a84fb99`，设计V1.15.1。实现为Cocos Creator 3.8.7真实3D渲染，浏览器仅为导出包开发预览。用户视觉体验待评审；真实手机与微信专属验证按用户授权豁免，未提交推送。

## 验证范围

- `baseline.json`固定179项既有检查及不可变模块hash；最终238项Node和类型检查通过，59项新增检查覆盖状态、存储、相对手势、几何、球面与同杆等价。
- Creator Web Mobile最终构建退出36（该版本成功退出码）。Main场景和原脚本.meta不变。标准受光effect由本地材质资源显式打包，不依赖运行时远程加载。
- `browser-320/393/430.json`分别记录54项合成DOM触摸与6项布局检查。控件至少44逻辑像素，HUD独立正交投影；模拟触摸不代表硬件触屏认证。
- `paired-shots.json`：16组固定球位、命令，实际Cocos帧循环在俯视/第一人称各出杆。每帧受控推进0.1s，只用于确定性对比，不用于墙钟时序验收；完整事件、进袋和裁判一致，终点误差0。自然时间220ms触球另由flow与audio-regression验证。
- `safety-393.json`：36位置×2观察高度，48个安全第一人称、24个水平杆受阻后的正确俯视回退。回退不是假称所有位置都能第一人称。
- `creator-native.json`：编辑器嵌入预览，引擎触摸入口注入；flow、safety、layout、pairs分列。实际缩放画布低于320宽使用320逻辑布局，不能替代手机认证。
- `legacy-regression.json`记录UI81、打点28、输入17、六袋28、轨迹16和AI45；`audio-regression.json`含A音效17、对局35与触球/中断9等独立记录。不要将嵌套同名时序重复计成新增用例。

## 视觉与资源

`checkpoints/`保留早期同渲染器的8张贴地调优画面和中间流程记录，仅作历史对照。最终构建证据以下方原生截图与浏览器录像为准。`visual-evidence.json`、`screens/`和`replays/`保存Creator画布中辅助开/关、阴影关的24张对照、72张安全机位图。浏览器实际画布另保存4段低/高观察往返、60/10FPS触球录像。几何值和图像观感分别检查，不以数值正确代替用户审美评审。

固定球心Y=0.028575m、clothTop=0、R=0.028575m，未沉球、变径或压扁；球面号码、连续环带与轨迹都接受深度遮挡。贴库对照使用高打点以保持水平杆体不被桌框遮住，数据中明确记录；中低杆的无解情况由安全矩阵检查回退。

性能见`performance.json`：393×852/DPR2、本机Chromium、60FPS上限；每场景预热1秒、采样10秒、3轮。包括俯视、第一人称静止、拖动、连续改线预测、静止完成预测和切换，共18段。帧率、P95、最大帧耗时及原始间隔全部保存，不等于移动设备性能。

连续改线时，密集球阵等待输入稳定550ms后启动原物理预测，稀疏台面仍70ms；过期结果立即清除。不可抢占的密集接触物理步仍可能产生单帧峰值，不能把P95通过写成每帧均不超时。50次切换资源/预测复用检查与GPU计数独立保存；`resource-plateau.json`另保留此前150次切换与5次重开稳定性诊断。

## 历史失败与限制

`failures/`保留首次材质未打包、LDR照度过大及密集预测调度前的性能失败。它们不作为最终通过画面。首次GPU分配上升经预热后稳定，不将高水位分配误称已证明泄漏。

Creator离屏画布captureStream输出空文件，已明确拒绝作为视频证据；录像改由导出包画布采集并检查非零文件与解码信息。

原生调试中手动刷新嵌入页面会使Creator内部SceneFacadeManager上下文失效，出现编辑器IPC错误；不是游戏物理异常。本轮通过重启编辑器并从Play入口重新运行恢复，不能宣称修复了Creator自身问题。

第一人称只改变显示和触摸瞄准。XZ物理、CBSA裁判、AI规划、球阵随机、力度曲线与220ms唯一提交模块保持hash一致。没有新增跳球、抬杆物理、弧线球、自由环绕、陀螺仪、自动追球或第一人称AI观战。HDR路径未单独验收。
