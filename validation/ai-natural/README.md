# AI 自然选线修订 V1.15.3

2026-10-26，基线08c0ad2。用户批准修正“有直接路线却先撞库”的AI选杆倾向。此处记录本地仿真与运行验证，不代表真实胜率、职业水平或所有台面都不会犯规。

## 策略与范围

1. 合法、能容纳该难度角误差的直接进攻/防守优先。直接进攻仍需仿真结果支持，不能强行打必犯规球。
2. 球心被挡时检查薄碰通路。仅剩无法容纳角误差的窄通路时，不把它假称稳定直接路线；只保留最多2个直接尝试，其余预算用于解球。
3. 入门/标准若已有合法稳定直接接触，不仿真后续解球。完全受阻或没有安全直接接触时仍保留解球。
4. 挑战主动一库进攻需名义+角/力误差四角点的5点全部合法、一次前置触库、首碰指定目标并进该球，均分比最佳直接路线至少高600；未完成检查不能凭名义高分主动绕库。5点不是实物成功率测量。

物理、球球接触、裁判、Shot/220ms提交、旋转、袋口、随机球阵均未修改。角度/力度误差值与最终两次LCG抽样不变；风险检查不消费游戏随机数。Game只增加riskReports开发日志。

## 修订前后同题对比

`before.json`与`after.json`为11个固定台面×3难度×2执行种子，共66例，均完整搜索名义候选上限；`comparison.json`汇总，不筛失败，不等于实时截止时一定搜索到同一候选。

原版的“直接”只有名义通路判定；新版本另检查角误差余量。入门仍有2杆先碰库且存在几何薄碰候选，但该窄通路没有足够角误差余量，属于保留的必要解球而非稳定直接路线被放弃。先撞库总杆数24→14，不以“越少越好”替代合法解球检查。

全部真实失误保留：修订后仍有5/66例执行后犯规或败局。此轮只改策略，不把已保留的难度误差改成必中，也不声称每个案例均改善。CPU耗时原值保留作诊断；两轮运行时机器负载不同，不作硬件性能对比。
