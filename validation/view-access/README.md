# V1.15.2 视角权限与贴库显示验收

用户明确要求：除摆球之外，不因阶段或球杆穿模拒绝第一人称。本修订替代V1.15.1的强制俯视、运动单向切换及贴库回退约束，旧证据保留历史状态。

当前仅placing强制俯视。开放选组、AI、开球处理、暂停、打点草稿、准备0–220ms、运动和结果均可双向切换；顶部入口优先于弹层接收触摸。AI不能人手代打，暂停仍冻结球，打点草稿不自动提交。

每杆开始时无论俯视还是第一人称都存相机出发位；运动中切换使用同一位姿，不追球。近库采用20cm局部半透明（Alpha110/255）、杆尾显示抬0–8°，原杆头世界位置不变；不改物理、旋转、力度、打点或捕获边界。透明部分与不透明部分使用同一几何代理，仅影响显示，离开后恢复。
