# 母球打点与简化旋转模型

对应 V1.9 已确认设计。球心仍只在 XZ 平面运动，新增 `wx / wy / wz`（弧度/秒）；不模拟跳球、抬杆、弧线球、杆头失误或球球摩擦造成的细微偏移。当前为可校准的简化仿真，不代表实测职业球桌。

## 坐标与输入

面板沿球杆看向母球，x 正为右塞，y 正为高杆。偏移归一化到单位圆，中心 0.1 半径内吸附；393参考画板选择圆半径60，因此对应中心6逻辑像素。越界按半径约束，不把横纵分量分别裁成正方形。组合偏移不会突破球面范围。

`TipSelection` 分离草稿和确认值，完成只应用、不出杆；取消撤销草稿；复位只修改草稿，仍须完成。切后台或暂停撤销未确认草稿，保留已确认值。点击出杆时将确认值复制到不可变本杆快照；准备和运动时禁止编辑。停稳并完成裁判结算后自动回中。

面板范围映射为实际接触偏移的0.64球半径。球杆显示使用同一映射，杆头的侧向、高度与球面深度跟随打点；物理绕水平轴和竖轴的初始旋转由相应偏移产生。高低杆与左右名称不随屏幕朝向翻转。

## 击球、台呢与碰库

按单位质量实心球近似，惯量为 `I = 2R²/5`。初始转速系数为 `2.5 × 0.64 = 1.6`，沿杆方向转换到桌面坐标。不同打点共享同一杆的总能量预算，因此偏心时初始平移速度会降低；力度百分比不等于固定平移速度或固定转速。

接触点相对台呢的滑动速度：

```text
ux = vx + R × wz
uz = vz - R × wx
```

摩擦冲量沿滑动反方向，同时改变平移和水平角速度。单步冲量取滑动速度除以3.5与摩擦加速度乘时间步的较小值，避免跨越无滑动状态引起数值振荡。达到纯滚动后使用滚动减速并保持滚动约束。

正碰目标球后，母球保留的水平旋转通过台呢摩擦产生跟进或回拉。距离增加时，滑动摩擦先改变旋转，回拉趋势可能减弱或消失；没有固定“回拉推力”。左右塞不在出杆时直接横移母球，主要经碰库时的接触点切向速度产生反弹差异。

碰库使用法向恢复系数和受法向冲量约束的切向摩擦冲量，切向速度与侧旋同时改变。球球碰撞仍保留现有法向等质量模型，不额外实现旋转传递或碰撞偏移。

| 参数 | 当前值 | 用途 |
| --- | --- | --- |
| 固定步长 | 1/240 秒 | 沿用现有求解器 |
| 最大力度速度预算 | 4 m/s | 偏心时分配平移与旋转能量 |
| 打点接触半径比例 | 0.64 | 避免极端球面边缘映射 |
| 滑动摩擦加速度 | 1.8 m/s² | 滑动转向滚动与高低杆效果 |
| 滚动减速 | 0.32 m/s² | 沿用台面参数 |
| 侧旋衰减 | 12 rad/s² | 简化的自转阻尼 |
| 碰库切向摩擦系数 | 0.18 | 限制侧旋反弹冲量 |

以上参数集中于 `BilliardsSpin.ts` 和 `TABLE`，用于当前游戏手感，不宣称为具体球桌的测量值。

## 停稳、复位与显示

停稳同时考虑平移速度与水平角速度对应的周向速度，防止母球平移暂时接近零时被提前结算。纯竖轴侧旋在此模型中不能独自重新驱动平移，因此整桌平移和水平旋转均停止后截断残余侧旋，避免无意义等待。

母球摆放、落袋、目标球重置清空角速度。新球阵默认零旋转。渲染累计物理子步中的角位移，用于球面和环带转动；球号继续由HUD投影显示。动画姿态不回写物理。

## 验收案例

- 草稿、确认、取消、中心吸附与圆形边界；同杆重新打开和结算回中。
- 固定近距离正碰：高杆跟进、低杆回拉；同力度低杆远距离回拉减弱。
- 相反左右塞撞同一库边，切向反弹方向相反；中杆不凭空产生侧向速度。
- 球杆朝向变化后，打点语义与角速度映射一致。
- 极限打点与组合打点保持有限数值，能量不增长，并在时限内停稳。
- 出杆快照保留原打点，触球前不移动、不转动；实际击球仍跟随220 ms触球帧。
- Creator 内通过投影坐标与引擎触摸分发入口检查面板、回显和实际球运动；与DOM和真机证据分别报告。
