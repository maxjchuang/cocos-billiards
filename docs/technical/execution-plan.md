## 证据与范围

完整机器报告见[acceptance.json](../../validation/ui-complete/acceptance.json)，图稿对照见[截图总览](../../validation/ui-complete/contact-sheet.png)，文字与纯色测量见[pixel-metrics.json](../../validation/ui-complete/pixel-metrics.json)。参考画幅56项布局检查，附加320×568 DPR1（安全区0/0）、430×932 DPR3（59/34）、393×852 DPR2（59/34）各45项；DPR3的引擎渲染仍上限2。

393主流程：原对局35、打点28、异常输入17、完整方案81、反馈12、受控球局14、袋口28、分辨率3；另有7项模拟生命周期和9项10 FPS逐帧检查。10 FPS时实际首动绘出约303ms，逻辑220ms触球与首动同帧且仅一次，不能承诺低帧率墙钟220ms必定绘出。

本机Chromium 3秒普通瞄准和3秒放大瞄准均约60 FPS，P95分别17.8/17.4ms；50次菜单往返组件数365不增长。此结果不推广到真机。模拟Cocos前后台事件不等于真实操作系统后台认证。

像素结论限定为同比例主控件/弹层/外框投影边界、S01文字纯色抽样与S01–S15人工视检；3D抗锯齿、球面滚动、宿主胶囊与状态栏不做逐像素相等承诺。PDF作为规范与索引，SVG和ui-contract.json作为像素基准。

Q04仍须在Mac解锁后从原生Creator启动预览复核。CLI成功构建后仍出现历史window.json编辑器恢复缓存错误，未将其混作游戏运行错误，也未改动用户编辑器配置。只有该原生界面复验尚未完成，不据此声称整个计划全部通过。Q05是用户豁免，不是通过。
