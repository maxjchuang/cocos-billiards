# 三状态触摸与后拉出杆实施方案

2026-11-08。用户已批准产品与UI/UX 3.0。首轮参数为交互原型起点。

## 架构与数据边界

继续采用Creator 3.8.7类型、当前安装的3.8.8编辑器、纯TypeScript XZ物理与独立裁判。新增纯手势模型负责8px/1.3倍轴向识别、96px后拉、4px零点、1.6幂力度、底部起点重设。BilliardsGame管理free/top/aim主模式、场景与控件归属、阶段权限与取消。CameraRig保存自由与俯视镜头，支持真实台面射线平移和240ms回位，正交俯视长边横向。

人类后拉松手通过原ShotSequence与commitShot入口提交。Sequence接收可选前送时长100+60×力度比例毫秒，默认220ms供AI及原有调用使用。记录母球出发点与显示后拉量，台面球杆从该位置前送，接触帧运行唯一提交。正时间步、声音与预测继续使用相同物理参数。取消或重复松手不可生成第二杆。

镜头和球杆方向独立保存。俯视按下立即瞄准，拖动每帧指向触点。双指加入恢复单指按下前方向，取消蓄力并按累计6px或4%识别平移/缩放，全部抬起重新开始。UI起手继续由UI独占。摆球单指编辑母球，AI及运动仅观察。

## 不支持的物理与赛事规则

球杆倾角仅为视觉贴库兼容，当前不增加跳球、扎杆、弧线球、身体犯规或完整职业赛事裁判。规则基线继续为README所引CBSA 2017年1月第三章。

## 已实现的文件与恢复规则

- BilliardsAimGesture.ts中的PullGesture负责方向识别、慢拖增益、力度曲线及底部起点重设。
- BilliardsGame.ts中的TouchMode保存主状态，沿用ViewState的渲染兼容层，V8模型在三模式中共用。CameraRig.top仅选择正交投影，自由与瞄准使用透视。
- 自由与俯视切换采用240ms遮罩过渡，120ms时切换投影；进入瞄准采用240ms位置插值。减少动态时直接就位。过渡期间模式控件保持选中反馈，台面单指等待到位。
- CameraRig.pan用屏幕射线与台面求交计算实际平移量，同时移动相机与锚点。俯视目标与缩放独立保存，自由观察位姿单独记忆。
- ShotSequence.begin增加可选contactMs，现有调用默认220ms。人类后拉使用100+60×力度比例毫秒，实际杆头由同一elapsedMs计算。出发点与确认打点用于触球姿态，触球后80ms送杆、再80ms淡出。
- 微调使用相对拖动，可多次起手累计，0.1度按钮步进；蓄力期间微调与打点保留位置并降低对比度。
- 新局清理触摸集合与归属，重复同指开始被忽略。尺寸变化、后台、暂停和第二指取消蓄力；双指退出等待全部抬起。

## 验收结果

289项Node测试与类型检查通过。Creator 3.8.8 Web Mobile构建成功，退出36。667×375 DPR2、852×393 DPR2、932×430 DPR3浏览器各48项合成DOM触摸通过，工程预览852×393另48项通过，均未记录error或unhandledrejection。10%、50%、100%力度的实际绘制帧检查3项通过，分别在106、130、160ms触球，触球前速度为零，接触帧杆头几何误差小于0.02mm，送杆淡出存在中间透明度。

原生Creator已重新打开Main并启动编辑器内预览，项目窗口可显示启动界面，观察到错误及警告计数均为0。原生系统鼠标点击未能可靠完成按钮释放，因此原生交互通过与否单独保留为未认证；触摸流程的执行证据来自浏览器与工程预览合成事件。真实手机、微信导出和开发工具按既有约定跳过。

产品5页、UI/UX23页与5张SVG/PNG图稿已生成并渲染检查。报告、源文件指纹和实际画面见[验收目录](validation/touch-modes/README.md)。本轮参数仍为手感校准初值。

## 2026-11-09 自由观察轻点修订

自由观察在合法瞄准阶段增加轻点瞄准，球杆在该模式可见。按下时记录逻辑像素位置，累计位移达到8px后取消轻点候选并开始环绕；轻微抖动保持镜头。松手再次检查回合、裁判、球运动、面板和触摸权限，通过当前相机的tablePoint与pointAt计算方向并显示触点反馈。移出再移回的拖动、双指加入、系统取消、新局、暂停与后台清除候选。自由观察的相机位置独立保存。

新增三项组件回归覆盖轻点与抖动、环绕回到起点、取消与权限变化，浏览器检查另覆盖松手时指向触点、相机保持及球杆实际可见朝向。

本次修订验收通过292项逻辑测试、Creator Web Mobile构建及三个横屏/工程预览各52项合成DOM触摸检查，页面错误为0。三档触球帧另3项复验通过。真实设备与微信沿用豁免。

## 2026-11-09 模式按钮、结算与辅助线修订

三模式入口去掉图标，文字居中，瞄准入口显示为瞄准击球。横屏结算采用独立内容区，身份行保留头像与昵称点击，底部两按钮均可操作。查看台面状态优先命中返回结果按钮，台面其他区域继续观察。

零力度和等待预测阶段使用独立的几何方向线与首碰轮廓，蓄力后恢复实际物理预测。几何预览复用网格并在无有效首碰或辅助关闭时隐藏。验证见[UI专项记录](validation/ui-fixes/README.md)。

## 2026-11-09 AI状态与结算身份居中

AI状态改为顶部回合区176×28的单行状态条，文字12px，实际文本宽140px，难度由身份卡独立展示。覆盖思考、摆球、开球选择、瞄准、准备出杆和球运动，暂停、面板与人类回合隐藏。状态提示与实际AI阶段同步，底部提示说明可切换视角观察。

结算按既有UI/UX居中层级排列头像、昵称、获胜标题，三个元素同一中轴。普通高度上边距中心偏移为50/96/136px，正文起始164px；卡片高度低于300px使用36/72/106px及正文130px。头像直径44px，紧凑时36px；昵称独立居中，身份区域保留可点击查看。正文与按钮继续分区避让。
