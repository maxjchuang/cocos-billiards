专项使用 `scripts/preview-table-v8.js`。包含资源、单位、三角形、纹理和绘制预算，20次局部处理，20次整桌创建/销毁，父节点旋转后的法线，七类阶段观察与球局不变性，4.5m远距离下的完整深度范围，以及六袋两档速度的下落、暂停、尺度与隐藏顺序。手势脚本为 `scripts/free-camera-smoke.js`，覆盖指数量变化、观察与方向分离、回位、220ms触球及运动中观察。

原生窗口由Creator打开Main并点击编辑器预览，项目控制台重启后错误与警告计数均为0。原生窗口的系统鼠标自动释放事件未取得可靠序列，交互认证使用引擎组件入口与工程预览的手机模拟。工程预览测试前需刷新已打开Main的预览，等待tableView出现及booting结束，避免使用热更新前的旧实例。

Creator引擎DevTools有getGamepad安全上下文提示，该模块未参与本游戏输入。一次CLI任务完成后出现窗口恢复缓存暂态读取提示，布局缓存随后校验为有效JSON，Main原生预览已重新启动。构建退出码为36。

## 几何及材质

[独立GLB接缝审查](asset-geometry.json)测得最大外片间隙约0.934mm。胶边接触线对齐及腿型采样在派生后校验，见资源记录。当前材质移除Creator不支持的两项扩展，木面漆层采用标准PBR近似，台呢使用显式低反光参数。

## 复现

先按资源记录确认源模型与游戏资产指纹，执行接入方案中的导出和构建命令。Web Mobile预览由 `npm run preview` 启动。在开发者控制台执行专项函数可复核组件入口。Creator工程预览应先在编辑器中打开Main并启动预览，桌面预览会过滤移动触摸入口，手机输入专项需明确启用手机模拟。
