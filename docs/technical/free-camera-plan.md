# 横屏统一界面与自由镜头实施计划

2026-11-04，对应产品与UI/UX V2.1。

## 架构

沿用Cocos Creator 3.8.7、TypeScript平面物理和既有裁判。CameraRig持有独立观察位姿，球杆方向、力度、打点继续由球局保存。回位根据当前母球和球杆方向求解，运动期间使用出杆时保存的起点。场景使用全屏透视相机。

触摸由场景与控件分别取得所有权。场景单指编辑瞄准或摆球，第二指加入时终止该次编辑，双指平移控制环绕和俯角、指距控制距离。双指退为单指须全部抬起后重新开始。暂停与旋转清理触摸所有权。

HUD根据安全区计算横屏位置，上方身份、左侧暂停和回位、右侧竖向力度、下方三个主操作。阶段动作替换操作区。竖屏提示和暂停恢复沿用原有阶段保存逻辑。

## 执行顺序与完成标准

- P1 镜头。默认高位，场景始终透视。环绕、缩放不改变球杆方向，回位对齐母球后方。运动期间回位使用保存起点。
- P2 输入。两指均从场景起始才能观察，AI与运动期间可观察。手指数变化、取消、暂停后没有旧触摸位移或额外击球。
- P3 横屏HUD。参考852×393及紧凑画幅控件无重叠，力度纵向编辑，触区至少44。摆球确认保留镜头，回位入口始终可达。
- P4 验证。运行类型检查、既有回归及镜头/多指专项测试。Creator导出浏览器后检查正常入口、摆球、回位、运动中观察及旋转恢复。分别记录自动检查与画面验证。

## 校准起点

回位约280ms，观察距离0.2至4.5世界单位，观察俯角约8至85度。这些数值作为原型初值，结合遮挡、完整球台和触摸手感调整。默认操作条左下、力度右侧，左右布局的可选设置纳入HUD验收。

## 进度

P1至P4已完成本轮本地实施与自动验收。

- P1。CameraRig独立持有观察位姿，回位动画280ms，可被观察手势接管。距离0.2至4.5，俯角约8至85度。新局和进入摆球推荐高位，确认摆球保留镜头。
- P2。场景两指同帧采样，超过5逻辑像素锁定环绕，指距变化超过约3.5%锁定缩放。退为单指等待全部抬起。保留AI、运动和查看结果台面的观察权限。

新增回归包括双指退为单指隔离、观察与击球参数独立、运动中使用锁定起点回位，以及引擎同帧平行移动的识别。

浏览器记录见 validation/free-camera/browser-checks.json，可重复检查入口为 scripts/free-camera-smoke.js。该脚本使用引擎组件触摸入口。Creator编辑器原生预览本轮未复核。真机与微信专项按已有约定跳过。

## 回到出杆位的起点生命周期修正

2026-11-04修复上一杆起点在结算后仍被使用的问题。syncShotCamera以实际阶段决定起点归属。未触球的准备阶段和shooting阶段保留本杆起点，其他阶段立即释放。已结算但按钮反馈动画仍在播放时也释放。回位入口主动同步该状态，避免等待下一次画面更新。

当前球位回位同时传入确认打点与力度。回位动画结束复制完整目标位姿，包含方向、打点、距离与高度信息。

266项测试通过，新增覆盖ready、placing、choice、over、触球前取消、运动中保留起点、反馈动画未结束时结算，以及完整动画位姿。Creator Web Mobile构建成功。浏览器通过实际回位按钮的组件命中入口验证了准备中保持起点、取消后释放、回到当前母球和方向保持。

本轮原生Creator正在被手动操作，桌面工具中断刷新。当前球局保留，内置预览需重启后加载新实现。验证明细见validation/free-camera/return-to-shot.json。

## 2026-11-05 Creator浏览器竖屏黑屏修正
