# 离线 AI 技术实现

2026-10-25。产品与交互范围见[人机练习](../design/ai-opponent.md)。不依赖网络模型或通用物理引擎，保留Cocos Creator 3.8.7/纯TS/触屏与现有裁判。

## 模块

- `BilliardsPractice`：验证并保存玩法和三档难度，使用独立存储键eight-club.practice.v1；存储失败仅降级本次有效。
- `BilliardsAI`：合法目标、进袋接触几何、遮挡/胶边筛选、候选生成、真实物理试打、独立裁判结算及评分、最终AI命令误差和可取消回合。
- `Referee.cloneForSimulation`：复制球组、犯规、线后限制、开球状态、贴库集合等；模拟器的球阵工厂独立于真实会话，不能消耗真实球阵日志。
- `BilliardsGame`：模式选择、玩家身份与当前生效难度、AI回合编排、触摸权限、同一ShotSequence/commitShot提交，以及暂停/后台/重开取消。
- `PanelsView`：开始对局、AI难度与扩展暂停菜单。原设置/音频署名、规则和判罚记录保留。

## 搜索与难度

| 参数 | 入门 | 标准 | 挑战 |
| --- | ---: | ---: | ---: |
| 候选试打上限 | 10 | 26 | 52 |
| 出杆角度误差幅度 | ±0.85° | ±0.22° | ±0.04° |
| 力度相对误差幅度 | ±9% | ±3.5% | ±0.8% |
| 走位权重 | 0.05 | 0.45 | 0.9 |
| 对手机会权重 | 0.05 | 0.4 | 0.9 |
| 进攻附加选项 | 中杆 | 简单高低杆 | 简单高低杆、一库进攻 |
| 思考时间上限 | 1.6s | 2.6s | 4.2s |

先按合法球组生成球—袋方向与母球接触点，利用当前球球摩擦和恢复系数的刚体近似补偿切球偏移；该估计只给出候选起点，最后以完整材料物理试算为准。先覆盖多条路线，再细化高优先级路线的力度、角度和打点，保留基本直接防守与碰库解球。无清晰路线时尝试有界方向采样，不能通过伪造首碰“保证合法”。

每个试打复制全部球与裁判，以同样240Hz推进、记录首碰/触库/进袋并调用finishShot。合法获胜最高分；提前黑八和犯规强罚；其余比较合法进球、续杆、首碰厚度、下一杆路线及对手机会。落袋后未完成目标的薄碰库进攻会降低评分，防止选择对误差过敏的擦边解球。

最终命令一次性加入该档角度/力度误差；不在运动中修正轨迹。种子只来自当前游戏与最近已提交杆号，不消费RackSession随机数；同一台面暂停后重新思考不会额外滚动执行误差。回合决策、评分和种子保留最近32条开发日志，产品界面不显示搜索参数。

## 时间与权限

AI工作每帧使用约3ms合作式预算，最多160个仿真步；单个物理步不可抢占，因此并非3ms硬实时保证。达到时间上限时选择已完成候选中的最佳杆；极端情况下可退回合法操作范围内的候选尝试，仍接受正常犯规判罚。试打最多120秒仿真时间，不将未停稳结果当作完整评分。

显示观察/思考后，AI用约450ms调整球杆与力度，再调用同一出杆时序；实际击球仍在220ms触球帧。AI回合禁止人手摆球、选组、瞄准、调力、打点和出杆，但允许暂停和查看身份。人类轨迹预测在AI回合隐藏，避免双重试算。

暂停清除未锁定工作，保留已锁定命令；触球前取消动画，恢复重新准备同一命令；触球后冻结并续演，不补打。设置的难度与当前生效难度分开，AI卡片直到下一次实际开始思考才更新。更换玩法或重新开局完全丢弃旧工作，无异步定时器或worker回调可复活旧杆。

AI自动接受违规开球后的自由球，使用同一placeCue/confirmPlacement完成合法摆放；线后自由球的越线要求和目标重置仍由裁判处理。首版不做多层极小极大搜索、学习型策略、自动难度或联网对战；难度以固定题库和实际体验校准，不宣称职业水平或通用胜率。

验证证据见[AI验证](../../validation/ai/README.md)；真实手机及微信验证按用户既有要求跳过。
