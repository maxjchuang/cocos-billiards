# A 方案音效：写实球房

2026-10-24：用户试听后选择A，授权优化并接入游戏。2026-10-25用户已验证游戏内音效通过，批准提交推送。本轮范围为出杆、球球碰撞、碰库、进袋、开球组合和合法获胜后的克制掌声；暂不加入裁判语音、循环环境声、界面提示声、音乐或电子奖励音。沿用现有“音效”开关，不新增声音设置。“本局规则”提供音频署名入口，保证单独分发游戏时也能查看CC BY素材的作者、来源与授权。

## 音色与素材

保持A的近距离、干净、克制方向。14段本地PCM WAV，44.1kHz/单声道，单段峰值约0.78：出杆3、碰球4、碰库3、进袋3、掌声1；低/中/强撞击由实际事件控制音量，音色变体避免重复机械感。开球由真实碰撞事件混音，不播放预制爆破或开球录像配音。

碰球和掌声以公开实录为基础；出杆使用台球实录瞬态叠少量拟音。碰库和落袋沿用A试听的拟音组合，**不是已测量的中式球桌专项实录**。公开MP3试听编码不能声称为无损原始录音；确认A方向不消除这些素材边界。完整来源、许可证与改编说明见[素材署名](../../../AUDIO-CREDITS.md)，资源时长和校验见[清单](asset-manifest.json)。

## 触发与混音规范

- 出杆声在图标220ms触球同帧播放一次，使用已提交母球的实际初速度选择轻重，不在按钮按下时播。
- 球球使用接触起始的法向接近速度，碰库使用反弹前法向速度，进袋使用移除球体前速度。只增加事件元数据，不改变物理系数、积分或判罚；已有开球终态逐值回归。
- 极弱碰撞低于0.035m/s不发声；其余音量随速度平方根平滑变化。球球、胶边、杆头、袋内保持不同音色与增益。
- 每个绘制帧，同一球对/同球同库边取最强一次；同键28ms内抑制接触抖动。最多选3次球球、2次碰库、3次进袋，进袋优先，不改变实际物理事件或裁判记录。
- 固定13个声音通道：出杆2、球球5、碰库2、进袋3、掌声1。正在播放的碰撞不被新碰撞stop重启；通道满时丢弃新请求。所有活跃通道音量和不超过0.9，为密集开球保留余量。
- 掌声仅在裁判确认该杆合法获胜后、结果层显示350ms后播放一次，长1.8s。提前进8、进8犯规、开球违规判负、普通进球或白球落袋不播放掌声。查看台面/重开结果层不重复庆祝。
- 自动结算暂停保留最后的落袋尾音。手动暂停、切后台、重开、销毁和静音停止所有声音并清除待播请求，恢复不补播旧声音。
- 声音选择使用独立循环索引，不消耗球阵随机数。音频失败不能阻塞触摸、出杆或裁判。

## 复现与验证

源录音保存于source/，仅用于离线编辑，不通过远程CDN加载。`scripts/build-audio-a.py`需要ffmpeg、NumPy和SciPy，重建时保留已有.meta UUID；游戏运行不依赖这些工具。新资源具有独立UUID，原四个音频的.meta保留。

验收应分别记录类型/Node、Web Mobile浏览器和Creator原生预览；真机/微信按已有用户豁免。关键检查包括轻重差别、音色变体、密集碰撞尾音与通道上限、350ms掌声一次性和犯规抑制、静音/暂停/后台取消、220ms触球同步、素材加载完整及原球局轨迹一致。记录见validation/audio-a/。
