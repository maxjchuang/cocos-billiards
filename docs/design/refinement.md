当前已经完成主要单局玩法、三档离线 AI、旋转打点、白金双色轨迹、暂停与结果等功能。问题不是重新做一套游戏，而是功能扩展后缺少一次整体设计收口：**部分规范过时、局部语义被挤占、球桌材料表现偏平、各类弹层层级过于相似**。

复核资料：产品 PDF 9 页、UI/UX PDF 27 页、S01–S17 SVG、ui-contract.json、design-manifest.json，以及 AI、轨迹、音效、袋口与放大窗补充规范。证据来自当前源代码和当前 Web Mobile 构建的新浏览器截图，使用独立浏览器上下文，未改变用户正在体验的对局。

本轮实际检查正常瞄准、AI 身份、开局、设置、打点、胜利、暂停等画面。S01 等截图采用仓库既有受控台面与 393×852 / DPR2 / 安全区47、34；它们用于视觉对照，不代表本轮重新完成真实整局或真机验收。开局截图采用浏览器真实安全区0，不能把其顶边差异算作设计错误。原生 Creator、本轮硬件触摸和微信没有重新测试。

## 3. 审美方案：专业球房 · 精修

### 总体气质

像一张光线柔和的球房俯视台面。背景退后、球桌居中、金色只引导动作和重要状态。避免厚重的全屏金边、拟真功能图标、木纹照片、霓虹光效、满屏粒子。对局期间的焦点顺序为：母球和目标球 → 当前行动 → 力度与出杆 → 身份资料。

### 配色与材料

| 背景 | #0E1C19 | 比台面更暗，不加入高对比纹理 |
| 面板 | #1C3028；弱底#15251F | 信息区与弹层的层次 |
| 台呢 | 中心#286556 → 边缘#1B4A3F | 低对比、无明显聚光圈；可选低于2%可见强度细纹 |

| 主操作 | #D9BD83；允许#E0C995→#D4B87D轻渐变 | 只给当前主要按钮；深绿文字#17372B |

| 判罚 | #DFB981；判负#D99588 | 必须同时给文字，不单靠颜色 |

球面光源统一位于左上约10–11点钟；阴影向右下轻偏移。大部分球面仍由球的本色构成，号码白底保持清晰；半色球始终是一整条环带。袋口采用深部暗、入口边缘微亮的低对比层次，杜绝用高光把洞口“描大”。袋口尺寸保持既有已批准代理。

### 各状态设计

- **正常瞄准**：双方身份常驻，当前玩家用头像圈/底色和行动文字共同确认。图例放在状态条右侧；手指移动时可显示“预测中”，稳定后恢复两球图例；力度条标题永远不被替换。偏心打点在右按钮显示金色描边及偏移图案。
- **AI回合**：卡片保持独立难度标签；思考、摆球、瞄准分别用明确短句。底部保持原占位，仅切换为等待区，避免桌面突然变大再缩回。进入正式出杆动效时保留可见的触球节奏，不输出伪造的思考百分比。
- **自由球/犯规**：“对手白球落袋 · 你获得全台自由球”与“轻触空位，再确认位置”成对出现。需要线后限制时文字与台面范围同步；异常摆位只强调错误点和原因，不在整桌覆盖红层。
- **开局选择**：玩法横向两项、难度横向三项，下方仅显示选中档说明，底部单一开始操作。初次进入没有取消入口；局中更换玩法有取消，开始之前不重置当前局。描述难度能力，不承诺职业水平或固定胜率。
- **暂停**：主按钮继续；其余为设置型列表行，玩法与难度显示当前值；重开位于底部低强调区域且仍有二次确认。调整难度提示“下次AI思考起生效”，已锁定一杆不改写。
- **打点**：母球176px、选择半径60px沿用；强化范围线和定位点。方向标签保持相对于球杆观察，不按屏幕方向解释。每杆停稳回中继续遵守原规范。
- **胜负**：获胜玩家与原因优先，8号符号作为小徽记；合法打进8和提前进8/犯规伴随进8分别写明。AI获胜也必须显示正确身份，不能统一写“你赢了”。
- **设置与规则**：主要字号和列表间距统一。更新辅助瞄准描述，保留五个现有设置、即时保存和存储失败提示；规则页与记录仍能访问，不为美观删去裁判解释。

### 运动与反馈

继续使用既有斜杆+空心球待机图标，微调/出杆/打点均为线框。总时长820ms，0–140ms后收，140–220ms击出，220ms杆头触球、台面实际击球和音效同帧，随后短线扩散、球离场、复位；减少动态模式仍保留触球同步。新面板建议180–220ms短距离进入，常规状态切换120–160ms；不使用循环呼吸高光或装饰晃动。仅采用已批准A音效，不新增裁判语音、环境声或UI声音。
