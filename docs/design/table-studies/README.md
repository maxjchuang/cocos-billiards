整桌及台面比例参考JOY Q8 Pro公开数据。约140mm边带为对称布置下的推算，鼻口高度、截面倾角、圆角、皮口和袋内尺寸均待校准。85/82mm为现有游戏候选参数。木材配色、桌裙及桌腿属于本游戏造型选择，具体参数以V8母版为准。结构示意用于解释关系。

通过 `python3 scripts/build-free-camera-design.py --uiux-only` 更新UI/UX主PDF、可编辑正文、设计契约、索引和本目录图稿。图稿绘制源位于 `scripts/table_visual_design.py`。完整来源与验收记录见主文档和 `design-qa.json`。

袋角修订使用独立的平面曲线研究。直库、转弯与袋内侧相切连接，台呢承托区与石板开口分别绘制。同类形态参考来自KNBB中式台球公开照片，曲率和具体尺寸待同型号资料校准。

T01、T09至T11已替换为V8母版实际渲染。早期AI概念图见[历史视觉探索](../table-renders/README.md)，当前执行基准见[已确认三维模型](../table-model/README.md)。
