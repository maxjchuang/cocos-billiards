# 瞄准轨迹与最终落点

2026-10-25，用户要求显示母球和目标球轨迹及最终落点，并明确母球使用白色。用户随后验证双虚线版本通过，批准提交推送。保留移动触屏操作和独立出杆，不修改物理参数、音效或裁判。

## 视觉与行为

- 母球：暖白色`#F5F1E6`虚线，1.35逻辑像素；最终停点为空心圆与中心十字。
- 首碰目标球：香槟金`#E5BD74`虚线，1.35逻辑像素；最终停点为空心菱形。回合条右侧独立显示白色母球与金色目标球图例；“击球力度”标题始终保留并可附已确认打点。此处由2026-10-25批准的V1.14精修规范替代旧版复用力度标题的做法。
- 金线先绘制、白色虚线后绘制；母球4px实段/4px间隔，目标球6px实段/4px间隔，同路段仍可辨别两球。实际球体与号码保留，辅助图不拦截触摸。
- “目标球”指母球本杆首次实际接触的目标球，包含先碰库后再撞球的情况。全桌其它球参与计算，只显示这两颗球的轨迹，避免开球时十几条线遮住台面。
- 同时显示碰撞前后、碰库及后续碰球轨迹，直到本杆所有球停稳；低力度未碰到目标球时只显示母球。
- 进袋时轨迹终止于预测落袋面，并显示入袋箭头和文字“入袋”；不在台面伪造停球圈。预测物理结果，不预测犯规后的自由球摆放、开球黑八重置等裁判安排。
- 仅在可以瞄准时显示；出杆准备、球运动、摆球、暂停、打点草稿弹层隐藏。沿用“辅助瞄准”设置，关闭后停止预测计算并清除图形。

## 预测机制与准确性边界

复制本杆球位、球号、物理槽位、质量、旋转与进袋状态，按实际方向、力度曲线和已确认打点调用同一个纯TS物理求解器，以相同240Hz固定时间步推演。不创建裁判/音效事件、不取随机数、不修改真实球位或球阵日志。

输入变更后立即移除旧结果，稳定70ms后开始分帧计算。每帧合作式工作预算约2ms、至多80个固定步；单次物理步不可中途抢占，因此此值不是每帧硬上限。计算期间显示“预测中”，只画已计算的路径，不画最终停点。时间步上限为120秒仿真；达到上限仍在运动时显示“未停稳”，不将预算终点误称最终落点。异常输入显示“暂无法预测”，不影响实际击球。

每4mm运动采样，碰库/碰球/落袋时额外保留点；完成后使用0.8mm世界误差阈值压缩折线，保留反弹转角及旋转造成的曲线。这只减少绘图点，不改变仿真终点。

采用当前已验收的平面旋转、接触、胶边和袋口代理模型；不承诺现实球桌的完整3D效果或真机性能。验证需覆盖实际出杆终点、旋转、碰库、入袋、输入失效、关闭/暂停和手机画幅。
