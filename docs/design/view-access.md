# 视角权限与贴库兼容 V1.15.2

2026-10-26。用户明确撤销“摆球以外的切换限制”和“因球杆穿模而退回俯视”。本修订替代V1.15.1中的对应状态、安全回退条款。

## 产品与交互

只有开局/犯规自由球等摆球阶段固定俯视，必须完成合法确认。其余阶段允许俯视与第一人称双向切换，包括未选组、开球处理选择、AI、打点草稿、0–220ms准备、球运动、暂停、结果及结束台面。顶部入口始终保留，仅摆球灰显；面板存在时入口显示在遮罩上层并独立路由触摸。

视角权限与玩法权限分离。AI回合不能人手代打；未选组不能绕过选组；暂停切换不恢复球运动；打点草稿不因切换提交或取消。切换不更改方向、力度或打点，不触发击球。连续点击反转视角目标；准备/运动/弹层内切换直接到位，避免把动画转场当作另一个禁用条件。

每杆在开始准备时，无论当时俯视还是第一人称，都保存母球出发位和方向对应的机位。运动中可反复进出第一人称，始终使用同一机位；不追球，不因切入时母球已运动而跳到新位置。停稳后按当前明确偏好定位下一杆。

## UI与显示兼容

球杆与库边相交不改变视角。近库（横向绝对值>0.50m或纵向>1.14m）时，以母球为中心、20cm见方的局部窗口，将相交库边和桌框显示为半透明；其余部分保持原材质与外形。退出第一人称或母球离库后完整恢复。保留袋口缺口，透明窗口不改碰撞/捕获几何。

杆尾显示抬角0–8°，以原杆头中心为旋转基点，杆头位置保持。该抬角只是避免显示穿模的视觉补偿，不是抬杆物理；不会改变旋转、出杆方向、能量或高低杆打点。仍受遮挡的近库部分由局部透明处理，不通过强制俯视、沉球、抬球或改打点解决。

镜头本体仍应避开实体，缩短后距/观察高度调整是显示适配，不限制视角选择。有效球位不因杆头/母球被库边遮挡而返回俯视。

## 验收

- 唯一不能切第一人称的阶段是placing；其它阶段真实触摸均可双向切换。
- AI、暂停、结果与打点草稿的原玩法状态和参数不变，弹层不吞顶部切换。
- 36位置×2高度全部保持第一人称；四库与近袋中低杆均不回退。
- 显示抬杆后，杆头中心世界坐标与原未抬杆坐标误差≤0.01mm；物理/裁判/AI/Shot模块hash不变。
- 0–220ms和运动中切换不取消、不重提实际击球；两视角仍逻辑220ms唯一触球。
- 临时透明网格在切换/位置变化时释放并恢复，反复切换无持续资源增长。

真实设备与微信专项沿用用户豁免，不能将本地检查宣称真机通过。
