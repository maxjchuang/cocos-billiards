## 当前执行基准

横屏使用统一界面与连续可调镜头，单指瞄准、双指环绕/缩放，入口为“回到出杆位”。球桌造型以用户确认的 `sketch-matched-legs-v8` 模型为准。

V8确认范围包括整桌、木帮、台呢、皮口、袋壁、桌裙、六条车枳圆腿和木脚座。外廓2820×1540×850mm，台面2540×1260mm，球径57.15mm。主腿身400mm/最粗166mm，上部连接段在桌裙下露出85mm，脚座直径92mm。细节尺寸为本游戏造型拟合，厂家精确剖面与实物校准单独记录。

主PDF第12页、20至23页使用同一模型的整桌、低位、袋口、桌腿及规范页。第13至19页保留结构关系和下落流程示意，实际轮廓与材质由V8母版约束。交互布局图在 `free-camera/`。

## 确认与运行状态

用户已确认独立三维模型造型。现有游戏仍使用程序化桌体，Creator模型资产导入、表现替换、材质迁移、贴库兼容与性能优化待按技术方案实施。模型浏览器检查和278项Node结果仅覆盖各自验证范围。

现有自由镜头交互范围依照产品规范与运行记录。本文未扩大其他交互评审项的确认范围。

## 生成与检查

```sh
python3 scripts/build-free-camera-design.py
```

生成两份主PDF、Markdown正文、图稿、设计契约及版本索引，副本位于 `output/pdf/`。UI/UX单独更新可使用 `--uiux-only`。模型重建和几何检查见模型目录说明。PDF需重新渲染检查排版，游戏与设备验收独立记录。
