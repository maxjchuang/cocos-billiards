当前游戏为同屏对战，已开始接入本地头像昵称与主题，已在代码中接入独立出杆动效、微调和基础辅助线，Creator运行验收待完成。母球打点与旋转尚待实现；未来联网状态图仅为设计预留。

出杆交互要求：点击锁定本杆参数，先后收再击出，在 220 ms 触球关键帧同帧触发实际击球且仅触发一次。调整动画时，实际击球跟随触球关键帧；不能在点击时立即击球。取消、防重复、减弱动效等完整约束见 UI / UX 文档。

V1.9 已确认：每杆停稳结算后打点回中；微调±5°、点按0.1°；局部放大默认开启；音效与辅助瞄准默认开，振动与减少动态默认关。设置本机保存，修改立即生效。详见 UI / UX 第23–24页及[技术实现方案](../technical/implementation-plan.md)。
