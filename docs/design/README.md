# 专业球房设计方案 V1.13

## 2026-10-25：人机练习与三档难度

已增加离线人机练习，保留双人同屏。开局选择入门/标准/挑战并记住上次选择；暂停菜单可修改AI难度，从下一次思考生效，已锁定或运动中的杆保持原参数。AI覆盖开球、选组、自由球、违规开球处理、防守、基本走位与黑八结算，沿用现有物理/裁判和220ms触球提交。AI回合只允许暂停和查看资料，不允许人手代打。

设计见[AI方案](ai-opponent.md)，实现见[AI技术方案](../technical/ai-opponent.md)，证据见[AI验证](../../validation/ai/README.md)。176项Node、Web Mobile构建、三个浏览器画幅和Creator原生专项通过；标准AI完整球阵31杆产生正常胜负。三档固定题库呈现整体能力差别，不代表通用胜率。真机/微信继续豁免。2026-10-25用户体验验证通过，批准提交并推送。


## 2026-10-25：分色轨迹与最终落点

辅助瞄准已扩展为母球白色虚线、首碰目标球金色虚线，分别标记最终停点；进袋显示箭头与入袋提示。使用当前力度、已确认打点和完整台面球位，在独立副本上运行相同240Hz物理，考虑后续碰球及反弹。分帧计算，输入变化立即清除旧结果；“预测中/未停稳”不显示最终停点，辅助开关可关闭。

规范见[轨迹与落点](trajectory-guide.md)，证据见[预测验证](../../validation/trajectory/README.md)。类型检查及159项Node、三个浏览器画幅与Creator原生预览专项通过；受控实际出杆的两球终点误差为0。真机/微信继续豁免，2026-10-25用户已验证双虚线版本通过，批准提交并推送。


## 2026-10-24：A 方案音效接入

用户选择A写实球房方向。现已接入14段本地声音素材与13个独立通道，覆盖出杆、球球、碰库、进袋和合法获胜后的短掌声；没有裁判语音、环境底声、界面提示音或电子奖励音。轻重取自实际接触速度，开球按真实事件混音，保留旧碰撞尾音；暂停、后台、重开和静音清掉待播声音。掌声在合法获胜结算后延迟350ms播一次，犯规和普通进球不播。原220ms触球同步保留，物理轨迹逐值回归一致。

音效设计与边界见[音效A规范](audio/README.md)，授权见[AUDIO-CREDITS.md](../../AUDIO-CREDITS.md)，游戏规则页内可查看音频署名。本轮验证见[音效验证](../../validation/audio-a/README.md)；2026-10-25用户已体验验证通过，批准提交并推送。


## 2026-10-24 已验收版本：hertz-reference-v6

当前正时间步使用带材料参数的Hertz有限接触，压缩状态跨帧保留、法线随实际球心更新，加入球间切向摩擦与侧旋传递；胶边/落袋事件按扫掠时刻耦合，避免末尾位置修正注入能量。旧归一化接触流程仅保留在dt=0诊断兼容入口，正式游戏不使用。
