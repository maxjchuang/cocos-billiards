## 当前执行基准

横屏使用自由观察、俯视观察、瞄准三种操作状态，俯视连续触点瞄准、瞄准后拉松手出杆、双指平移观察锚点。球桌造型以用户确认的 `sketch-matched-legs-v8` 模型为准。

V8确认范围包括整桌、木帮、台呢、皮口、袋壁、桌裙、六条车枳圆腿和木脚座。外廓2820×1540×850mm，台面2540×1260mm，球径57.15mm。主腿身400mm/最粗166mm，上部连接段在桌裙下露出85mm，脚座直径92mm。细节尺寸为本游戏造型拟合，厂家精确剖面与实物校准单独记录。

```sh
python3 scripts/build-interaction-design.py
```
