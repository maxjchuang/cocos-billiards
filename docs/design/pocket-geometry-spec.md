## 校准整桌比例

采用JOY Q8 Pro公开的**同一型号**内外尺寸作为整桌视觉参考。假设台面居中、两侧对称，宽度方向整体边带为（1540−1260）÷2=140 mm；长度方向为（2820−2540）÷2=140 mm。

140 mm是整体边带的推算值，包含库边和外侧结构所占空间，不能解释为胶条单独宽度或某处木板实测厚度。

以整桌外宽250 px排版：

| 元素 | 换算值 |
| --- | --- |
| 整桌外高 | 457.79 px |
| 内台面宽 / 长 | 204.55 / 412.34 px |
| 每侧整体边带 | 22.73 px |
| 台面球直径（沿用57.15 mm） | 9.28 px |

S01–S17保留原有球桌区域的高度，根据上述比例重算外宽与内沿；球位和球杆图形随内部空间等比调整。袋口恢复为可辨认的视觉原型：开口净宽采用BOJUE候选85/82 mm，相对57.15 mm球径约1.49/1.43倍；球体同步按物理比例绘制。袋内后沿曲线仍为未量测示意，不能当作碰撞边界。精确球径换算以G01和上表为准，旧状态图的号码标牌不作为毫米量具。

设计提交24ebe9a时，游戏台面为2540×1270 mm。随后用户授权实现，已按技术方案显式将宽度迁移为1260 mm；长边不变，头线与置球点保留，边界与回归同步迁移。此变更不等于精确复制该型号袋口。

## 中袋必须分开表达的结构

1. **胶边入口与袋角**：控制球先撞到哪里，以及撞后怎样改变方向。
2. **石板开孔与支承边缘**：决定球何时失去支承，与胶边最窄处不是同一条轮廓。
3. **皮口与承接部件**：位于开孔周边或下方，有遮挡与厚度，不能用同一个黑色闭合路径同时表达全部部件。
4. **下方袋网或回球通道**：承接下落的球，不是平面上的捕获圆。

G02用曲线缺口说明上述关系，标注“结构示意 / 非本型号工程图”。曲线绘制在像素空间中，不提供其半径、椭圆轴长、袋内纵深或落袋线数值；不得把图中黑区直接导入为碰撞和捕获区域。

## 撤销的V1.10参数

- **18 mm中袋浅椭圆后沿、55 mm洞口总深、12.4 mm外侧余量**：没有实物尺寸支持，撤销，不能继续作为项目实施值。
- **67.4 mm台边约束**：由旧UI反推而来，不是真实球台尺寸；不能再据此压扁袋洞。
- **12 mm袋角半径、25 mm支承区、统一半圆后沿**：同样未获所选型号工程图或测量支持，从实施配置移除。
- **85 / 82 mm组成完整单一型号参数**：只保留为BOJUE独立配置的候选资料，不与JOY整桌尺寸拼接成已核验套件。

数值在manifest中明确设为null或移入withdrawnV110，不用零表示，也不保留代码可读取的有效默认值。

## 落地前的资料与验收要求

需要同一型号的袋口正俯视资料和尺寸图或测量，明确胶边开口的测量位置、石板开孔曲线、皮口边缘、支承边界与球径之间的关系。拿不到精确资料时，可以做明确标注近似的视觉原型，但不能声称精确复刻，不能把照片透视造成的浅扁轮廓当作真实开孔。

核验后才建立共享几何，并统一程序模型、物理胶边、进袋、合法摆球与辅助线。回归覆盖六袋正向、低速/满力、擦袋角、斜角、沿库、袋前不提前消失、白球落袋犯规及非法摆球。逻辑、Creator/浏览器、手机和微信平台分别记录，设计核验不代表运行验收。

## V1.12 视觉修订：袋口不能画成小点

V1.11以微小圆点替代袋口，导致入口小于球，视觉表达错误，现已取消。所有页面恢复可辨认的开口，采用BOJUE候选85/82 mm，相对57.15 mm球径约1.49/1.43倍；同时校准台面球体大小。整桌外框仍按JOY公开比例，整套图是明确标注来源的视觉原型，不声称属于任何单一型号的完整实物复刻。

袋内采用圆弧收口的示意路径，不恢复18 mm浅弧或55 mm纵深参数。示意路径不参与物理配置。已核验整桌比例、开口与球径比例，以及示意袋口位于台框内；精确胶边轮廓、石板开孔和失去支承位置仍待同型号资料。
