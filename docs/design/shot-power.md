# 力度手感修订：加强高力度与开球

2026-10-23。此规范替代旧版“力度与0.4–4 m/s线性对应”的速度预算；力度条、默认60%、触摸操作与220ms触球时序保持既有规范。

| 显示力度 | 中杆初速度预算 |
| --- | --- |
| 10% | 0.4 m/s |
| 25% | 1.0 m/s |
| 50% | 2.0 m/s |
| 60%（默认） | 2.4 m/s |
| 70% | 3.05 m/s |
| 80% | 4.2 m/s |
| 90% | 5.85 m/s |
| 100% | 8.0 m/s |

10%–60%保留原有控制范围；60%以上平滑、逐步增加速度，满力上限由4提高到8 m/s。开球和局中共用此曲线。高低杆与侧塞沿用相同击球能量预算的分配，实际平移速度由打点决定。

点击出杆只锁定力度，220ms杆头触球关键帧才将显示力度映射为初速度，并且只提交一次。触球前取消、暂停和恢复规则保持。

物理继续使用240Hz外层固定步长；高速情况下内部按位移预算细分碰撞子步，以减少穿球、穿库风险。它仍是离散平面仿真，不代表连续碰撞检测或现实球台的精确标定；不保证每杆都进球或所有球都彻底分离。

验收使用标准球阵、中杆、母球位于开球线后正中与左右偏0.12 m并瞄准顶球。相对旧满力4 m/s，新满力须满足：目标球累计帧间位移至少2倍、一秒时未进袋目标球包围盒面积至少1.5倍、至少7颗不同目标球触库、15秒内停稳且数值有限、球未越出外框。既有规则、六袋与触球时序另行回归。

此为本项目手感调优参数，不是厂家或赛事认证数据。可复现实验与实际Cocos结果见validation/power。
