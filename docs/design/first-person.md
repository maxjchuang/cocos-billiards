### 首版冻结值与安全边界

后距0.45m，安全候选0.40/0.35m；眼高默认0.20m、范围0.15–0.25m，向前看0.38m；垂直FOV55°，near0.01m、far6m。淡切280ms，中点切投影；阈值6逻辑像素、主轴优势1.3倍，水平每场景宽60°，垂直每场景高0.20m再限幅。这些为本地验证参数，用户手感评审后仍可调整。密集球阵在瞄准稳定550ms后启动完整预测，稀疏球局70ms；等待时显示“预测中”，输入变化立即清除旧结果。

真实球半径0.028575m，clothTop=0、球心Y=R。固定方向光、受光球面、1024阴影贴图与台面接触阴影；号码贴在球面，后球号码与轨迹按深度遮挡。桌框、胶边与袋内为视觉网格，不改既有碰撞代理。

贴库中低杆若水平球杆实际被桌框遮挡，安全相机也无法补救，则回俯视并提示、保留偏好与全部参数。高打点可存在安全机位，不为展示效果自动改打点或抬杆物理。

## 1. 产品目标与范围

提供“俯视观察 + 第一人称瞄准”双视角。第一人称模拟玩家俯身沿球杆看向母球：母球位于画面下方，杆头靠近母球，球杆从下方伸入，目标球在前方；镜头不安装在球心，也不随滚动母球旋转。

两种视角共用同一球局、球位、瞄准方向、力度、打点、物理、裁判与轨迹预测。切换不会重开、自动选球、改角度或立即击球。相同一杆命令的物理结果必须与视角无关。全程触摸，不新增键盘、鼠标、陀螺仪或双指缩放的依赖。

首版提供人类瞄准的双视角；AI回合保持现有俯视观察，避免视角自动跟随AI选线跳转。AI回合可访问暂停/资料，不允许人手代打；人类重新获得可击球回合时恢复其偏好。AI第一人称观战、自由环绕、自动追球、跳球/弧线球另行评估。

## 2. 状态与切换规则

区分“偏好视角”和“当前展示视角”。偏好在本机保存，首次默认俯视。被规则或安全原因临时切回俯视，不覆盖偏好；存储失败沿用既有提示，本局仍生效。同屏模式首版为设备共享偏好，不新增账号或分席存储。

| 阶段 | 当前展示与允许操作 | 恢复规则 |
|---|---|---|
| 初始选择玩法、开局摆球 | 俯视；不允许第一人称摆球 | 确认合法位置后按偏好进入瞄准 |
| 开放局选组、开球处理选择 | 俯视；先完成裁判要求的选择 | 允许瞄准时恢复偏好 |
| 正常瞄准/微调 | 可切换两视角；相机与方向按下文手势控制 | 微调打开时切换先收起调节条，保留最终方向；不重置基准外的真实方向 |
| 打点草稿弹层 | 冻结进入弹层前视角，切换入口不可用 | 取消保留原打点；完成只应用打点，返回同一视角 |
| 出杆准备0–220ms | 锁定相机姿态、方向、力度、打点；禁用切换及拖动 | 220ms可见触球同帧唯一提交实际击球和声音 |
| 球运动 | 第一人称固定在出杆时机位，不追随母球；允许一键切回俯视 | 运动中不允许从俯视新进入第一人称，以免锚点移动产生突跳；临时俯视不覆盖偏好 |
| 停稳正常续杆/换人 | 台面稳定且裁判允许后，重新定位到当前母球后方 | 按偏好进入下一杆；不在球仍运动时追到新位置 |
| 犯规自由球/开球重摆 | 强制俯视，显示全台或线后摆放范围 | 合法确认后恢复偏好；不能在第一人称绕过摆放确认 |
| AI回合 | 首版俯视，仅暂停/资料可用 | 不覆盖人类偏好，轮回人类再恢复 |
| 暂停/后台/横屏 | 保存视角与本杆上下文，按现有暂停规则冻结 | 返回须明确继续；不自动出杆，触球后不重复提交 |
| 胜负/查看结束台面 | 俯视展示结果与整台 | 新局仍先俯视摆球，确认后恢复偏好 |

## 3. 入口、触区和版式

底部保持“微调 / 出杆 / 打点”三项和独立力度条。视角入口放在顶部导航，使用当前模式文字，与暂停入口同为次级按钮；可访问名称说明切换目标，例如“切换到第一人称”。触摸一次切换，不弹出额外菜单。

393×852参考：暂停触区x14/y47/44×44；标题x68/y55/72×24；模式副标题保持11号字；视角入口x148/y47/68×44。宿主菜单参考区域x285/y50/92×32保持预留，不自绘宿主按钮。320宽视角入口缩为56×44，右沿204；宿主预留从212起，至少8px间隔。宿主实际胶囊/安全区优先；极窄空间下先简化标题，不把视角入口放到袋口上。

俯视仍使用V1.14球桌外框参考273.05×500；第一人称使用相同的可用场景区域x20/y193/w353/h500呈现透视场景，**这不是要求透视画面中的桌框仍为273.05×500**。HUD身份、力度和三个主按钮不随透视缩放。微调展开时沿用52px让位；短屏先压留白、再缩场景区域，触区不小于44。

被阶段限制时入口保持位置，低对比禁用且不占用触摸；运动中的第一人称显示“俯视”作为返回动作。首次进入只显示一次“左右滑动瞄准，上下调整视角”的短提示，不长驻遮挡台面。当前模式通过按钮文字表达，不单靠图标或颜色。

## 4. 第一人称手势

- 左右相对拖动控制击球水平方位角，镜头围绕当前母球跟随杆线调整；手指不必拖到目标球上。
- 上下相对拖动调整观察高度/俯仰构图，不修改击球方向、力度或打点，不提供抬杆击球能力。
- 起手超过小位移阈值后按主要轴锁定本次手势；未确定主要轴时不修改方向。斜向起手保持待判定，达到主轴优势后再应用；抬手重新开始一段。
- 触屏边缘可抬手再拖，保留上段结果；新触点不是新的绝对瞄准目标，不产生角度跳变。
- 微调仍以打开时方向为中心±5°，点按0.1°，适用于两视角。拖动力度、打点、菜单按钮不会传入场景手势。
- 单一有效手指拥有当前操作；第二指、系统触摸取消不出杆、不抢占、不触发切换。
- 只允许沿当前杆线调整观察，不提供独立左右自由环绕，以免“看到的方向”和“实际出杆方向”分离。

首版值：起手阈值约6逻辑像素，主轴优势约1.3倍；横向每屏宽对应约60°，随后以长台/薄球/贴库样例调节。首版冻结值以上方实施记录为准。必须保留微调进行精确修正。

## 5. 相机构图与安全

早期候选范围（首版冻结值见上）：母球后方0.35–0.55m、台面上方0.15–0.25m、垂直视野角50–60°。视野角明确为垂直角，竖屏下实际横向覆盖由画幅决定；最终值须通过原型验证。基本目标：母球约位于场景区域下方2/3–4/5处，杆头、母球和当前接触关系能辨认，不能用缩放球体制造近大远小。

镜头位置受母球、当前方向及用户观察高度约束。贴库、近袋、球杆后方空间不足时，按“合法缩短后距 → 抬高视点 → 退回俯视”寻找安全构图；调节到限制只停止继续移动并短提示“已到视角边界”，不突然旋转瞄准。安全解恢复时不反复抖动，当前一杆保持已选安全机位；下一杆重新评估。

退回俯视提示“此位置已切回俯视，瞄准方向保留”。该退回是展示降级，不改偏好、球位、力度或打点。不能为防穿透推开球或修改球袋。

视角切换采用280ms短淡切；运动路径先保证不穿模，复杂情况下可使用安全淡切。切换期间不接收场景拖动和出杆，完成后恢复输入，避免出杆时镜头还在移动。减少动态模式立即切换但保持状态与220ms触球时序。

## 6. 模型、号码、轨迹与遮挡

第一人称图稿中的桌框侧面、库边厚度、袋内暗部是必须补齐的视觉结构；不能只倾斜现有俯视镜头后发布。新增视觉面不改已批准碰撞/落袋边界，也不构成厂家实物尺寸声明。

球体使用与场景一致的固定光源，半色环带仍连续绕球。号码应正确贴附球体或采用受深度遮挡约束的标识，禁止后方球号穿过前方球、库边或球桌。远球不强行放大号牌覆盖球形；当前目标球号继续在HUD图例中说明。库边的自然遮挡保留；需要看全局时切回俯视。

两视角使用同一份当前力度/打点的完整预测结果。母球白虚线、目标球金虚线，末点圆十字/菱形或进袋箭头保持语义。第一人称中的线、接触球和停点必须按透视与深度表现，不能把原俯视HUD圈原样覆盖上去；不可穿透球体/库边，也不可显示镜头背后的投影。

轨迹在视野之外或被遮挡，属于“预测结果存在但当前不可见”，不同于“预测中/未停稳/不可预测”。提供简短“全轨迹见俯视”提示，切回俯视显示完整两条轨迹；不为了塞进画面改写或删掉预测数据。屏外终点不在屏幕边缘伪造停点。

局部放大首版仅在俯视瞄准/微调时显示；第一人称暂时隐藏，用户的放大开关不被改写，回俯视继续遵循避袋策略。第一人称通过抬高观察和微调确认接触关系，避免两个不同透视的窗口同时竞争注意力。

### 6.1 球与台呢接触感修订（V1.15.1）

用户反馈V1.15图稿的球像漂浮在台面上。该版使用屏幕渐变圆和偏移黑色轮廓，缺少落在台面上的接触阴影；辅助线位于球心高度，也加强了悬空感。FP02–FP05已重绘，新增FP06近景细节；这是一项设计修正，不是已完成的运行修复。

- 球心的展示高度必须等于台面高度加球半径，球底与台呢相切；不能通过下沉球体、缩扁轮廓或夸大球径掩盖问题。
- 球体轮廓、接触点和阴影使用同一相机与台面投影。接触阴影位于台面上，接触核心较深、外围柔和；随距离和观察高度自然缩放、压缩，不能用屏幕空间偏移的黑圆替代。
- 球面保留本色，使用小而柔和的高光、平滑暗部和统一的固定光向。避免大片白色贴片、硬分界灰色半球和粗黑轮廓。
- 第一人称轨迹的路线部分贴台面呈现，数据仍为同一份XZ预测；接触球与停点另按各自空间位置表达。不得把整条路线悬在球心高度，造成球和线一起浮起的视觉暗示。
- 远近球、库边接触暗部与球下落影在方向上保持一致；观察高度变化后阴影不能与球脱离，也不能跟随视角变成另一个独立物体。
