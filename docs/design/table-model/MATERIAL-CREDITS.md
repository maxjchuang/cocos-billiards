# 模型材质来源

## 胡桃木木纹

- 作品为 American Walnut Veneer，作者为 Jenelle van Heerden，发布于 Poly Haven。
- [素材页面](https://polyhaven.com/a/american_walnut_veneer)
- [Poly Haven CC0 授权说明](https://polyhaven.com/license)
- 使用文件为 `textures/american_walnut_veneer_diff_2k.jpg`，在模型材质中加入暖棕染色与透明漆层，并按构件方向设置UV。
- 素材以CC0发布，许可商业使用及再分发。访问和下载日期为2026-11-06。

## 造型参考

- [乔氏Q8 Pro公开产品资料](https://www.joybilliard.com/billiards-table/golden-leg-billiards-tables.html)
- [KNBB公开乔氏中式球桌实拍](https://www.knbb.nl/chinese-pool-komt-naar-nederland/)

实拍用于比较木帮、包布和皮口的形态关系。模型中的木面宽度、倒角和皮口外沿为本轮视觉拟合参数。

## 其他表面

布面、皮革与金属材质由本仓库建模脚本生成。浏览器预览使用Three.js，代码许可证保留在 `THREE-LICENSE.txt`。
