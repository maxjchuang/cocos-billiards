# 人机练习与可调难度

## 2026-10-26 自然选线修订

用户反馈AI在能直接击球时仍先碰库，因此新增明确的选杆优先级：稳定的直接进攻、直接防守优先；直接接触被阻挡或过于狭窄、无法容纳该难度的角度误差时，才考虑解球。中路被挡但侧面能薄碰，不直接当作完全被挡。

入门/标准在已有合法且稳定直接接触试打时，不再试算后续解球。挑战可以主动一库进攻，但名义命令加角度/力度误差四角点均须合法、先碰指定目标并进目标球，且比较后的收益明显更高。5点通过是本机模型内的有限抗扰动检查，不是实物成功率或职业水平认证。

候选预算和思考时间有界，来不及完成主动绕库检查时保守保留直接路线；完全受阻时保留合法解球尝试，不能为了禁止绕库故意空杆。AI仍按当前难度一次性加入出杆误差，允许实际失误及裁判正常处罚。

只调整策略，不改球速、物理、袋口、裁判、人类输入或220ms触球。界面不显示评分和仿真参数。验证含全部固定案例与失败结果，见[专项报告](../../validation/ai-natural/README.md)。以下为原有玩法与交互范围。


2026-10-25：用户已体验验证通过，批准提交并推送。

2026-10-25，用户批准实施。首版提供离线人机练习与原双人同屏模式，AI固定为第二席，玩家先开球。开局选择入门/标准/挑战，保存上次选择；暂停菜单可更换玩法或设置AI难度。更换玩法需在新对局面板点击开始才重置，取消保留当前球局。

三档共同遵守CBSA 2017裁判，使用相同物理、球袋和220ms触球动效，不修改运动结果。难度由候选搜索数量、力度/打点选项、后续进攻与防守权重及最终出杆误差共同控制。入门优先简单进攻和合法碰球；标准加入简单高低杆与走位评估；挑战增加一库路线和对手机会评估。没有自动升降难度。

AI回合覆盖违规开球接受台面、合法自由球摆放、开放选组、正常出杆、开球重摆、黑八阶段与裁判结算。自由球由同一个Referee.placeCue/confirmPlacement确认。违规开球首版优先接受台面取得自由球，不伪造判罚或跳过选择。

界面显示AI头像、昵称和独立的当前生效难度标签。V1.14开局采用玩法/难度分段选择；AI思考、摆球、瞄准期间以固定占位等待区替代人类控件，正式出杆时仍展示共用触球动效。AI思考和瞄准期间允许暂停/查看资料，禁止人手修改AI的方向、力度、打点、选组、摆球和出杆。AI采用同一套球杆与出杆图标动效；只有220ms触球关键帧提交击球。AI不显示人类的完整预测辅助，以免重复计算遮挡台面。

暂停时尚未锁定的计算取消；恢复后按最新难度重新思考。已经锁定的一杆保留原难度、方向、力度、打点，触球前暂停取消原动画，恢复后用同一参数重新准备；触球后冻结并继续原杆，不能重复提交。难度修改从下一次开始思考生效，不能改写已锁定或运动中的杆。

技术采用纯TS候选生成、几何遮挡筛选、全桌同物理试算和独立裁判副本评分。AI工作分帧，约3ms合作式预算，不承诺单物理步可抢占；每档具有候选和思考时间上限，超时使用已得到的最好结果。没有联网模型、第三方物理或远程素材。输入误差只施加在最终AI命令，玩家输入不增加误差。

首版难度是固定题库上的能力分档，不承诺职业等级、真实胜率或每局绝不犯规；极端遮挡时会尝试碰库解球，实际失误仍由裁判处罚。需保留题库失败案例与实际对局日志，验证等级总体趋势及取消/暂停安全。真实手机/微信继续按既有授权跳过，Node、浏览器和Creator分别报告。
