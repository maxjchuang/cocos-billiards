## 布局结构

画面分为上沿身份、中央球台、两侧工具与下沿操作四个区域。第一人称和俯视使用同一组控件坐标。球台构图和界面信息密度分别调整。

|区域|组件|布局规则|
|---|---|---|
|上沿|双方头像、昵称、球组、剩球、行动方|两个148×44身份条。行动方用金色短线与文字共同标识。昵称省略后可打开详情。|
|中央|球台、母球、球杆、目标及轨迹|俯视完整六袋，保持真实比例。第一人称按母球与目标组织构图。|
|左侧|暂停、视角|暂停44×44，视角44×56。简洁显示、左右布局和帮助收进暂停菜单。|
|右侧|力度|44×144触区，当前百分比常驻。拖动调力，松手保留。|
|下沿|微调、出杆、打点|共享224×48背景。三项触区各72×44，18px线框图标、12px标签横排，出杆用72×40金色表面强调。|

## 交互关系

- 本稿提出默认左下操作条、右侧力度的双手分工。此项等待本轮评审。暂停菜单提供左右布局选择，操作条内顺序始终为微调、出杆、打点。
- 操作条在当前手势结束后执行主动换位，连续按下或拖动期间固定。摆球确认、选组、开球处理等阶段在相同操作区呈现相应动作。
- 瞄准时显示完整操作条。AI行动与球运动时，出杆及参数编辑进入只读状态，保留暂停、视角与局势观察入口。
- 微调在操作条上方展开短角度条。打点以258×304临时面板替换操作条，左右布局决定面板归属侧。图稿面板位于母球左侧，预留观察间隔。
- 打点编辑保留草稿语义。完成应用，取消恢复原值，复位仍须确认。编辑期间力度只读，视角仍可切换。
- 点击出杆锁定方向、力度与确认打点。220ms触球关键帧同步提交实际击球和音效。
