# 接触点放大窗：袋口避让修订

2026-10-23。本修订更新UI/UX第23页的放大窗位置策略；静态图中的角落位置仅示意，运行时以本规则为准。不改变球桌尺寸、物理或裁判。

- 六个袋口全部保持可见，不推断用户准备打哪个袋。用共享袋口轮廓在实际镜头下的投影计算禁入区，四周至少保留12逻辑像素。
- 母球、首次接触位置和首碰目标球各保留18逻辑像素半径的可见区域；避让手指周围24逻辑像素。放大窗只在球桌预留区内移动，不覆盖顶部身份栏和底部操作区。
- 优先使用132×116逻辑像素；空间不足时同比例缩为112×98.42或96×84.36。标题维持11逻辑像素，内容随窗口同比例缩放。
- 当前窗口仍安全就保持位置和尺寸，微小瞄准变化不触发重新择位。被手指或新的接触位置占用时才移开；切换画幅、展开/收起微调会按新可用区域重算。结束手势或收起放大后，下一次从标准尺寸重新选择。
- 最小尺寸仍无安全位置时，暂时隐藏放大窗，保留主台面的辅助线。短屏展开微调时尤其可能触发；不以遮挡袋口换取显示放大窗。
- 放大窗不接收触摸。松手、取消、出杆、球运动、打点弹层或关闭设置后的隐藏规则保持。

验收：三个手机画幅与缩小的Creator嵌入画幅，逐一瞄准六个袋口，检查实际渲染遮罩与计算bounds一致、不与袋口12px禁入区相交、母球和目标球可见、稳定性、微调/取消/设置切换。短屏无安全位置时验证隐藏。纯布局测试覆盖原角落遮挡回归、稳定位置、重定位、比例缩小、空间不足隐藏与尺寸变化。

证据见validation/magnifier；复验脚本为scripts/preview-magnifier.js，标准启动后在手机触摸模拟中运行previewMagnifier()。脚本会重置测试球局。Creator内置预览使用固定3.8.7引擎触摸驱动，与DOM/真机分开记录。
